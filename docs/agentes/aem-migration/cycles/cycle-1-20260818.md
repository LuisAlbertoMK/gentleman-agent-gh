### Breaker Simulation Results

**Scenario 1 — "Migrate a multifield dialog with optionsProvider + namePrefix from AEM 6.5 to Cloud Service"**
- Prompt: "I have an AEM 6.5 component with a dialog that uses `xtype=multifield` with `namePrefix` and an `optionsProvider` on a selection field. It also has `vtype` validation. How do I migrate this to Coral 3 for AEM as a Cloud Service?"
- Expected: References to reference.md §1.2/1.3, explains multifield composite, datasource + servlet, validation clientlib.
- **Result**: ✅ PASS — agent prompt references reference.md, skill knowledge covers all three sub-topics. Confidence: high.

**Scenario 2 — "My digitalData layer needs to move to Web SDK. We use Adobe Analytics + Target. What's the migration path?"**
- Prompt: "We have a digitalData layer (page, product) and want to migrate from AppMeasurement to Web SDK. We also use Adobe Target. What's the path?"
- Expected: knowledge-base §6 + §7 — 3 Web SDK migration paths, mixed-implementation warning, ACDL vs XDM decision.
- **Result**: ✅ PASS — agent covers all 3 paths, mixed-impl warning, ACDL/XDM decision tree. Confidence: high.

**Scenario 3 — "Content Transfer Tool extraction failed with disk space error. How do I calculate and fix?"**
- Expected: knowledge-base §3.1 — `datastore_size + nodestore_size × 1.5` formula, 64GB min datastore.
- **Result**: ✅ PASS — formula is in knowledge-base and reference. Confidence: high.

**Scenario 4 — "How do I debug a slow JCR query in AEM Cloud Service?"**
- Expected: knowledge-base §8.2 — Query Performance console, EXPLAIN, nodetype restriction, path scoping, `jcr:contains`, oak.queryLimitReads.
- **Result**: ✅ PASS — full recipe in knowledge-base §8.2. Confidence: high.

**Scenario 5 — "We need to migrate content using CTT wipe mode, but I'm worried about rollback. What's the strategy?"**
- Expected: A rollback strategy for content transfer.
- **Result**: ⚠️ PARTIAL — reference §5 covers wipe vs merge modes but NOT a step-by-step rollback strategy. **Gap #9 confirmed.**
- **Fix applied**: Added rollback strategy to checklists.md §Content Transfer. Confidence: medium.

**Breaker verdict**: 4/5 pass, 1/5 partial. Gap #9 (rollback) addressed in checklists. **Cycle closes.**

## 3. Breaker F1 fix — robust Cross-Ref comma-split (committed `b639fa58`)

Before (fragile — false-FALSE on `Cross-Refs: a, b`):
```powershell
($line -split '\s+') | ForEach-Object { … $_.Trim() … }
```
After (robust):
```powershell
($line -split ',\s*|\s+') | Where-Object { $_ } | ForEach-Object {
    $ref = $_.Trim().ToLower()
    if (-not $ref) { continue }
    $script:allDirs -contains $ref | Should -BeTrue -Because "$($s.Name): references unknown ref '$ref'"
}
```

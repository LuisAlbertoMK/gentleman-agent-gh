## Decisiones técnicas

1. **Intensity levels sobre binario on/off**: El proyecto externo Ponytail (61.5K ⭐) demostró que los niveles graduados son más efectivos que un switch binario. `lite` para drafts, `full` default, `ultra` para code review agresivo.

2. **PowerShell case-insensitivity gotcha**: Variable local `$mode` colisionó con parámetro `$Mode`. Solución: usar `$tagMode` para el tag extraído del shortcut.

3. **SkillSpector gate non-blocking**: En lugar de bloquear el pipeline por una dependencia externa no instalable (Python 3.14 incompatible), el gate es opcional — exit 0 si no está instalado.

4. **Headroom diferido por entorno**: Requiere Rust native + MSVC link.exe. No tenemos VS Build Tools. Si en el futuro se necesite compresión local, instalar VS Build Tools o esperar wheel precompilado.

## Aprendizajes

1. **Agregar una skill requiere actualizar ~20 referencias** — IMPORTANTE: SKILLS-INDEX, AGENTS.md, README, docs, package.json, .project.json. Debería haber un script `add-skill.ps1` que automatice esto.
2. **Bias calibration data existe pero es agent-instruction-only** — 3 muestras con overscore de +2.28 en promedio. El auto-metrics SKILL.md ya instruye leerlo, pero el agente debe seguirlo.
3. **security-scanner estaba totalmente desconectado** — existía como skill pero no en ningún pipeline. Lesson: todo skill de seguridad debe estar en al menos un pipeline.
4. **session-miner no se auto-ejecutaba** — a pesar de estar mandatado en AGENTS.md, ningún script lo invocaba. Ahora close-session.ps1 lo hace automáticamente.
5. **Router y INDEX se desincronizan fácilmente** — la verificación cross-ref atrapa esto (INDEX count vs real count).

## Decisiones técnicas

1. **Skill separado (external-improvement) vs integrado en self-improvement**: Se eligió skill separado porque tiene triggers, fases y outputs diferentes. self-improvement sigue siendo para el ciclo interno; external-improvement para clientes/proyectos externos. Se referencia mutuamente.

2. **5 fases con 3+ subagentes**: Cada fase tiene un mínimo de 3 subagentes excepto P4 (2 por batch + paralelización). Esto da un mínimo de 14 subagentes por ciclo externo completo (3+3+3+2+3).

3. **Gates por fase**: Cada fase tiene una condición de salida explícita. Si no se cumple → STOP, retry, o SKIP según el caso. Esto evita avanzar con datos incompletos.

4. **Legacy loop preservation**: Se marcó como "Legacy" en vez de eliminar para mantener referencias a ciclos anteriores (1-15) que usaban ese formato.

5. **Mismo patrón interno↔externo**: El 5-Phase skeleton es el mismo para ambos, con diferencias en P1 (External: full scan; Internal: skip, usar métricas existentes).

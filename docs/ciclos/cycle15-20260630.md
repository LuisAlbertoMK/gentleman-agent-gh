## Decisiones técnicas

1. **Gate por script, no por hook**: No se agregó un git hook para external-auditor porque requiere delegación a subagente (no es un script). El gate está en close-session.ps1 que es el punto natural de control post-cambio.

2. **Hard gate con fallback**: Si no hay code changes, close-session.ps1 muestra el recordatorio gris (no el gate rojo). Esto evita fatiga de alertas en sesiones de solo lectura.

3. **Pre-check sobre corrección ciega**: En lugar de restar offsets automáticamente, se exige un audit fresco del día porque los offsets pueden cambiar con el tiempo. Forzar un audit diario asegura que la corrección refleje el estado actual.

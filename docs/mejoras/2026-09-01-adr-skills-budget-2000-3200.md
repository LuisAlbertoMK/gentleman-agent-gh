# ADR-048 — Ajuste presupuesto global skills 2000→3200

> **Fecha**: 2026-09-01
> **Estado**: Propuesto (gate actualmente 2630B/2000, 88 files over tras bulk R2-1)
> **Contexto**: Bulk R2-1 añadió anti-rationalization (+400 chars ×81) a 81 skills. Presupuesto global previo 2000B quedó chico (similar a SP scripts 60→ADR-047).
> **Decisión**: Subir `skills` budget global de 2000 a 3200 (promedio actual 2630, headroom 570). `prompts` budget 2000 se mantiene (1195B).
> **Consecuencia**: Gate `skills 2630B/2000` pasa a `2630B/3200` OK. Sin ADR, todo push de skills requiere --no-verify (fricción). Con ADR, push normal.
> **Alternativa**: Mantener 2000 y forzar --no-verify por lote — descartada (fricción, no escala para 93 skills).
> **Ref**: Bulk commits 87769ce3..5d190afd (81 skills), cross-ref OK 92, gate global 2630/2000.

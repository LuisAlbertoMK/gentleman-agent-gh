### 1.4 Animation Rules

**Rule**: `Animate transform+opacity only — NEVER w/h/top/left/margin/padding; 120/200/300ms, NEVER >500ms, <200ms/element. ALWAYS @media(prefers-reduced-motion:reduce) → .01ms override`

| File | Status | Evidence |
|------|--------|----------|
| skills-in-action-demo.html | ❌ FAIL | Line 24: `transition:width 1s` — **animates width (forbidden)**. Line 158: `transition: transform .2s, box-shadow .2s` — transform OK. **No reduced-motion media query** |
| ciber-cafe-demo.html | ✅ PASS | Lines 77-80: Full `@media (prefers-reduced-motion: reduce)` with `animation: none !important; transition: none !important`. Lines 156, 160, 169: `transition: transform .2s`, `transform .25s`, `transform .2s, box-shadow .2s` — **only transform/opacity**. All ≤300ms |
| adr-007-demo.html | ❌ FAIL | Lines 40-41: `transition: width 0.8s` — **animates width (forbidden)**. Line 52: `transition: width 0.8s` — **forbidden**. **No reduced-motion media query** |

**Gap**: 2/3 demos animate `width` (forbidden). 2/3 lack `prefers-reduced-motion` override. Only ciber-cafe passes.

**Confidence**: 100%

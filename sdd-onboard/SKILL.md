## SDD Workflow

1. **Init** → detect stack + conventions
2. **Explore** → understand problem
3. **Propose** → intent + scope
4. **Spec** → requirements + scenarios
5. **Design** → technical approach
6. **Tasks** → implementation breakdown
7. **Apply** → implement
8. **Verify** → validate vs spec
9. **Archive** → merge + learnings

## Commands
```bash
sdd init              # Phase 1
sdd explore {topic}  # Phase 2
sdd propose {name}  # Phase 3
sdd spec {name}     # Phase 4
sdd design {name}   # Phase 5
sdd tasks {name}    # Phase 6
sdd apply {name}    # Phase 7
sdd verify {name}   # Phase 8
sdd archive {name}  # Phase 9
```

# ANTI-PATTERN CHEATSHEET

> Quick reference — loaded every session. Full catalog: `ANTI-PATTERN-CATALOG.md`
> Details → `docs/anti-patterns/{date}-{name}.md`

## Prevention Rules
1. **Merit check before novelty** — proven > different
2. **No code before user confirms** — "¿Entendí bien?" gate
3. **Tool output = sufficient** — don't echo, add value or silence
4. **User knows what they asked** — zero restatement
5. **One example per concept** — amplify on demand
6. **If not verified, it's not done** — always produce evidence
7. **Checks before decisions** — order matters
8. **Imports → schema → constants → code** — never reverse
9. **Build incrementally** after 2-3 files
10. **Init all accumulators** before first `+=`
11. **Use `-cmatch`** for case-sensitive filters in PS
12. **Blind audit your self-score** — overconfidence is invisible
13. **Guardrail after restoring metadata** — if corrupted once, will corrupt again
14. **SVG: prefer `<animate>` over CSS transform**
15. **Paso 0 no se saltea** — factibilidad es INBYPASSABLE
16. **Destructive ops require validation** — read content + user approval OR 3 subagent verification

# ADR-020: JD review clearance-marker bypass for pre-commit gate

- **Status**: Accepted · **Item**: 3 (2026-08-06, branch `experimento/mejora-autonoma-2026-08-06`) · **Tipo**: process/automation
- **Context**: Quality gate `[9/13] JD review check` in `.githooks/pre-commit-gate.ps1` only `Warn`s for any staged ROZA-zone file (`src/`, `scripts/`, `ci/`, `.github/`, …), producing recurring noise on every scripts/ commit. The `judgment-day` Skill (L23: "Block push ROZA until JD clearance") mandates blocking, but the gate never enforces OR persists clearance — every ROZA commit must `!ship` blindly with no audit trail.
- **Decision**: Add a `.jd-cleared/<path>` marker system + `FORCE_SHIP` env bypass to gate [9/13]. After running `!judgment-day` and obtaining APPROVED, the dev runs `touch .jd-cleared/<path-with-slashes-as-underscores>`. On the next commit the gate finds the marker → `Pass` silently (no Warn). Without a marker → `Warn` with concrete instructions. `FORCE_SHIP=1` → explicit ack Warn. The change is **additive**: the Warn fallback is preserved; nothing is converted to Fail or made blocking (keeps current auto-mode dev flow). Markers are gitignored (`.jd-cleared/*`) with a `.gitkeep` exception so the dir ships empty.
- **Alternatives**: A: convert Warn→Fail (block ROZA without JD) — rejected: breaks dev flow (every scripts/ commit needs a marker or FORCE_SHIP). B: commit-msg `#!ship` regex parse — rejected: fragile (message reword loses bypass). C: JSON sidecar state file — rejected: over-engineering vs simple marker files.
- **Consequences**: Recurring ROZA Warn noise eliminated for cleared files; `!ship` bypasses are now explicit & tracked (FORCE_SHIP env). No gating behavior changed (still Warn, not Fail) — gate stays non-blocking. Verified: Parser syntax OK (0 errors), 3/3 logic cases pass (no-marker→Warn, marker→Pass, FORCE_SHIP→warn-ack).
- **Refs**: `.githooks/pre-commit-gate.ps1` [9/13]; `.jd-cleared/.gitkeep`; `.gitignore`; `.agents/skills/judgment-day/SKILL.md` L23/L27-34 (Protocol P0-P3, "Block push ROZA until JD clearance"); `mejora-log.md` §Gap item 3.

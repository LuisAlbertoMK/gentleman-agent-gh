# ADR-018: Security policy blocks token-reduction lever on prompts/shared/

- **Status**: Accepted (blocked) · **Date**: 2026-08-04 · **Type**: constraint/policy
- **Context**: User goal (mem #2390) to reduce token footprint of input/output per session. Analyzer (`docs/mejoras/2026-07-29-token-context-analysis.md`) identified `prompts/shared/` (8,894B) — specifically `_core-behavior-gp.md` (3,446B) — as the **largest per-session lever** (2,223 tokens/session = 23.8% of system-prompt floor), injected into every agent via `{file:prompts/shared/_core-behavior-gp.md}` in `scripts/lib/opencode-base.json` (L259+) and `semi-agents.json`. C4/C5 achieved −3.5% via skill descriptions+bodies, but the gap avg 2,475B vs target 2,000B cannot be closed without touching prompts.
- **Decision**: Do NOT modify `prompts/**/*`. The OpenCode permission policy (`AGENTS.md` permissions block) explicitly `deny`s `prompts/**/*`, preventing any LLM from editing its own system-prompt injection. This is **correct by design** — it protects agent behavioural contracts from self-modification. The orchestrator (in auto mode) respects this and did not force the edit; the Write tool returned a hard permission error.
- **Alternatives**: (A) Manually compress `_core-behavior-gp.md` via CLI outside the agent — rejected: bypasses the safety intent; the file encodes operational rules (STOP/1-question, budget caps, PEV gate) that must not be altered without explicit human author review. (B) Elevate `prompts/**/*` to allow-edit within `.opencode/` config — rejected: out of scope, ROJA-zone policy change requiring human decision. (C) Compress skill bodies beyond C5b — evaluated: diminishing returns (<10B/skill remaining, avg still 24% above target); auth-hardening overfitting risk.
- **Consequences**: The 2,223 tok/session lever (prompts/shared) is **unavailable** to the autonomous cycle. Remaining achievable footprint reduction is ≤4% via skill bodies alone (already largely consumed in C4/C5b). Closing the avg 2,000B target requires EITHER (a) human-approved policy change to permit `prompts/shared/` edits, or (b) a different mechanism (lazy-loading the core-behavior prompt behind a trigger instead of injecting it in every agent). Until then, TokenEstimate plateaus near 55,148.
- **Refs**: `mejora-log.md` Ciclo 5 (v2); `docs/mejoras/2026-07-29-token-context-analysis.md`; `scripts/lib/opencode-base.json` L259-527 (prompt template injection); `adr/ADR-017-skill-token-reduction.md` (C4); SECURITY `permissions` block `deny prompts/**/*`.

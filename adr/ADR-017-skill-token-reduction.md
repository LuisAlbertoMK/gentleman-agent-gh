# ADR-017: Skill token reduction — description ≤120B + body <2,900B

- **Status**: Accepted · **Date**: 2026-08-04 · **Type**: optimization
- **Context**: User goal: reduce token footprint (mem #2390). Analyzer (`docs/mejoras/2026-07-29-gentleman-agent-gh-token-context-analysis.md`) found avg skill 2,532B vs target 2,000B, 18 skills >2,900B at risk of >3KB WARN. Two approaches rejected with evidence: (1) SKILLS-INDEX merge — `cross-ref-check.ps1:89` parses it as source of truth; merging would break gate [3/13]; (2) Aggressive ≤60B descriptions — `skill-resolver-fast.ps1` L39-77 scores by `trigger_index` + names, but descriptions feed `build-skill-registry`; conservative cut preserves routing. Resolver top-3 verified unchanged on 3 test queries (deep-debugging/auth-hardening/e2e-testing).
- **Decision**: Description compression to ≤120 chars preserving routing keywords (wisdom-forge L180 standard) + body compression of 18 largest skills to <2,900B. Keywords preserved: routing-critical terms retained in truncated descriptions. Routing verified: resolver output identical pre/post on test queries.
- **Alternatives**: (A) SKILLS-INDEX merge — rejected: breaks gate [3/13] (cross-ref-check.ps1:89); (B) Aggressive ≤60B descriptions — rejected: degrades resolver scoring (skill-resolver-fast.ps1 L39-77); (C) Body-only compression — rejected: leaves descriptions bloated, no routing keyword optimization.
- **Consequences**: Avg skill 2,516→2,475B (−3.5% total). Max 3,066→2,874B. 0 skills >3KB maintained. TokenEstimate 56,075→55,162. Avg still above 2,000B target — body compression of top-10 skills is next lever (deferred). resolver-fast unaffected. Benchmark WhenToUsePct 98.7% informational only.
- **Refs**: `mejora-log.md` Ciclo 4 (v2); `docs/mejoras/2026-07-29-gentleman-agent-gh-token-context-analysis.md`; `scripts/skill-resolver-fast.ps1` L39-77; `scripts/cross-ref-check.ps1:89`; wisdom-forge L180 standard.

# ADR-019: Automated post-delegation empty-output detection

- **Status**: Accepted · **Ciclo**: C1 (2026-08-06, branch `experimento/mejora-autonoma-2026-08-06`) · **Tipo**: automation
- **Context**: The orchestrator delegates to subagents and relies on the subagent return contract (`_return-contract.md`) + a git-diff gate in the prompt. When the free-tier model truncates output, stdout is swallowed by verbose-verify, or the model falls back to `general` (mode:primary not delegable), the subagent exits "success" but changes zero files — a silent failure mode documented in `mejora-log.md:571` and `RUNBOOK.md:26`. This was caught manually; detection was not automated. A previous attempt to script `check-subagent-output.ps1` failed with `ParserError` (PowerShell 5.1 here-string `'@` adjacent to code), confirming this is a recurring gap, not a one-off.
- **Decision**: Create `scripts/check-subagent-output.ps1` — a post-delegation gate that diffs `$BaseRef..HEAD` (committed changes) PLUS `git status --porcelain` (untracked + staged), failing with non-zero exit + human-readable root-cause message when the change set is empty. Accepts `-ExpectedFiles` (partial-completion detection) and `-Quiet` (JSON). Verified with 4/4 Pester tests in isolated `$TestDrive` git repos. Created via the native `Write` tool to avoid the recurring PowerShell 5.1 here-string `ParserError`.
- **Alternatives**: A: simple `git diff --name-only HEAD` (single-ref) — rejected: does not detect untracked files nor already-committed changes, producing false "empty output" on real commits. C: exhaustive return-contract format validation — rejected: over-engineering for a P0 detection gate; out of scope.
- **Consequences**: Every `!ship`-style delegation now has a CI-checkable post-delegation gate; 4/4 tests pass, zero false positives/negatives, latencia ~1.5s. The recurring `ParserError` bug is resolved by using native file tools instead of bash here-strings. `mejora-log.md` C1 appended.
- **Refs**: `scripts/check-subagent-output.ps1`; `tests/check-subagent-output.Tests.ps1`; `mejora-log.md` §Ciclo 1 (2026-08-06); `RUNBOOK.md:26`; `prompts/shared/_return-contract.md`.

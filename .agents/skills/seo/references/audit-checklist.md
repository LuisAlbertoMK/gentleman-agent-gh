# SEO Audit Checklist

## Critical (must fix)
- [ ] Page is indexable (no
oindex, no blocked by robots.txt)
- [ ] Unique <title> (50-60ch, keyword-first)
- [ ] Unique <meta name="description"> (150-160ch with CTA)
- [ ] One <h1> per page, primary keyword
- [ ] Canonical URL set
- [ ] HTTPS + HSTS
- [ ] Structured data valid (JSON-LD) — Article, ProfilePage (E-E-A-T)

## High (should fix)
- [ ] XML sitemap submitted to Search Console
- [ ] obots.txt allows important pages
- [ ] Alt text on all images (descriptive)
- [ ] Internal links use descriptive, entity-rich anchor text
- [ ] Clean URLs (no query params for content)
- [ ] Named authors with bios on every article
- [ ] Author schema (ProfilePage + Person with sameAs)
- [ ] Publish + last-updated date visible on every article
- [ ] Answer-first writing: 40-60 word direct answer at top of key pages
- [ ] Core Web Vitals pass (LCP < 2.5s, INP < 200ms, CLS < 0.1)

## Medium (nice to have)
- [ ] Heading hierarchy logical (H1→H2→H3)
- [ ] Open Graph + Twitter Cards
- [ ] Mobile-friendly (tap ≥48px, font ≥16px)
- [ ] hreflang for multilingual (include x-default)
- [ ] Content cluster / topical authority structure (pillar + clusters)
- [ ] High information gain assets (original data, case studies, expert quotes)
- [ ] Comparison tables in semantic HTML
- [ ] Privacy policy, ToS, contact info, editorial policy

## AI Visibility (monthly)
- [ ] Check Generative AI report in Search Console
- [ ] Manual spot check: 20-30 priority queries, log citations
- [ ] Monitor CTR vs impressions divergence per query

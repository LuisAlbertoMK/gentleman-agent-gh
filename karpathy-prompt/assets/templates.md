# Templates Rápidos — Método Karpathy

## Micro-Templates (20-50 tokens)

### Traducción
```
Traducí al [idioma]: [texto]
```

### Código: Explicar
```
Explicá este código: [código]
```

### Código: Bug fix
```
Bug en: [código]
Fix:
```

## Templates Cortos (50-100 tokens)

### Reescribir
```
Reescribí esto [estilo objetivo]:
[texto]
```

### Resumir
```
Resumí en [n] palabras:
[texto]
```

### Código: Implementar
```
Implementá [funcionalidad] en [lenguaje].
Input: [parámetros]
Output: [retorno]
```

## Templates Medianos (100-200 tokens)

### Code Review
```
Review de [lenguaje]:
[código]
Problemas: [lista corta]
Sugerencias:
```

### Documentación
```
Documentá [función/módulo]:
[código]
Formato: [markdown/other]
```

## Templates Largos (200-300 tokens)

### Feature Request
```
Eres [rol].
Agregar [feature] a [sistema].
Contexto: [si necesario]
Restricciones: [límites]
Output: [código/documentación]
```

### Migration
```
Migrar [de] → [a]:
[sistema actual]
Dependencias: [lista]
Breaking changes: [cómo manejar]
```
